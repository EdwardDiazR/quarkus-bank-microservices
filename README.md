# 🏦 Quarkus Bank Microservices

Sistema de microservicios bancarios construido con **Quarkus** y **Java 21**

---

## 🛠️ Tech Stack

* **Framework:** Quarkus (RESTEasy Reactive, Panache)
* **Lenguaje:** Java 21
* **Base de Datos:** Oracle DB
*
